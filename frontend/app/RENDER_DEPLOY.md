# Deploying Echo Sim to Render

Echo Sim is configured for fast, reliable deployment as a **Static Site** on Render. Render Static Sites include free SSL, global CDN, automated deployments from GitHub/GitLab, and 0s cold-start delays.

---

## Method 1: Deploy via Render Dashboard (Recommended)

1. **Push your repository to GitHub / GitLab**.
2. Go to the [Render Dashboard](https://dashboard.render.com/) and click **"New +"** → **"Static Site"**.
3. Connect your repository.
4. Configure the deployment settings with the following values:

| Field | Value | Notes |
|---|---|---|
| **Name** | `echo-sim-assistant` | Or your preferred name |
| **Branch** | `main` | Or your current branch |
| **Root Directory** | `frontend/app` | **Important**: Tells Render to build from `frontend/app` |
| **Build Command** | `npm install && npm run build` | Builds TypeScript and Vite production bundle |
| **Publish Directory** | `dist` | The output directory generated by Vite |

5. **Environment Variables**:
   Click **"Add Environment Variable"**:
   - `VITE_USE_MOCK` = `true` (enables the autonomous streaming backend simulator for the demo)
   - *(Optional)* `VITE_API_ENDPOINT` = `https://your-backend.onrender.com/api/chat` (if connecting to a live backend)

6. **Single Page Application (SPA) Routing**:
   A `_redirects` file is included in `public/_redirects` which redirects `/*` to `/index.html` with status `200`. Render automatically processes this to prevent 404 errors on page refreshes.

7. Click **"Create Static Site"**.
   Render will build and deploy your site in ~1 minute and provide an active URL (e.g. `https://echo-sim-assistant.onrender.com`).

---

## Method 2: Deploy via Render Blueprint (`render.yaml`)

A pre-configured `render.yaml` file is provided in `frontend/app/render.yaml`.

1. Go to [Render Dashboard](https://dashboard.render.com/) → **"Blueprints"** → **"New Blueprint Instance"**.
2. Select your repository.
3. Render will automatically detect the configuration in `render.yaml`, set up the build command (`npm install && npm run build`), static publish path (`./dist`), SPA rewrite rules, and environment variables.
4. Click **"Apply"**.
